# Tasks Workspace

This directory is the volatile workspace for planning and execution notes.

## Structure

- `active/`: in-progress exploration and execution records
- `archive/`: completed historical records
- `templates/`: reusable task templates

## Usage Rules

- Use this directory for new work plans.
- Keep uncertain exploration in task docs until stable truths emerge.
- Promote only stable, reusable, expensive-to-rediscover truths into durable docs.

## Mode Guidance

- Mode A (exploration): add exploration docs here only; do not change durable docs or production code.
- Mode B (solidification): restate scope and affected durable layers; update durable docs only after confirmation.
- Mode C (execution): restate scope and invariants; then implement tests/code and record outcomes.

## Templates

- `templates/exploration.md`
- `templates/execution.md`
- `templates/result.md`
