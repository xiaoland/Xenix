# 两项 oracle 误判修复

用户在全量测量后授权先修复聚类和商品相似推荐的误判，并在验证后授权整理提交。本次修改仅涉及两个用例、共享的交付表读取及 Unit TDD；不修改题面、fixture、生产 Harness 或其余四项失败，不新增回归测试或 benchmark 自测。

## 变更

两个 oracle 现在从最终答复的公开 Artifact 链接直接读取表格，检查用户实际能拿到的文件；删除扫描全部 Dataset、要求单一父链及重复匹配 Artifact 元数据的逻辑。内联 apply 无需伪造父数据集，未链接的正确中间结果不再可能被当作交付。

聚类将列集合完全相等改为包含必需列，因此允许额外诊断信息；六条原始记录、特征值与正确分群仍须成立。推荐仍要求 SKU-A 的两行结果按 rank 对应 SKU-B、SKU-C。两个用例共用 `linked_tables`，失效链接不能建立交付，图表不替代表格；未预期的服务和表读取异常向上暴露。

## 验证

- 一次性离线实验用原轨迹 SQL 重建含额外诊断列的真实 XLSX Artifact，并用原模型、角色、参数和内联输入重新执行原生推荐 FIT/APPLY。两项新 oracle 的业务与源数据完整性检查均通过；删除最终链接或换成不存在的链接时均失败。见 [回放证据](oracle-repair-replay.json)。这些是新建隔离存储中的回放，不冒称恢复了已清理的历史导出文件。
