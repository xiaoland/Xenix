# v2.0.0 互動設計

## 產品意圖

這份互動設計定義了一個面向商業資料分析與挖掘的操作流程。使用者可以從新建任務開始，也可以直接選擇過往模型。圖中以「預測」作為主範例，並且列出其他分析場景及其主要輸出形式。

## 場景目錄

系統在場景層提供以下分析類型：

- 預測：輸出實際值 vs 預測值、未來趨勢圖、誤差分布圖。
- 分類：輸出高風險名單、概率分布圖、關鍵影響因素圖。
- 聚類：輸出客群畫像卡片、各群體規模和價值、群體特徵對比圖。
- 異常檢測：輸出異常樣本清單、異常分數排序、時間分布圖。
- 異常檢測：原圖再次出現同名卡片，本文按原圖保留。
- 關鍵因素分析：輸出關鍵因素排名圖、影響方向圖、單因素影響曲線、變量分布對比圖、因素組合分析、自動業務解讀。

## 啟動入口

系統在開始時提供兩條主路徑：

- 新任務
- 選擇過往模型

這兩條路徑共同通往場景選擇；原圖以「預測」作為詳細展開案例。

## 路徑一：新任務

### 整體流程

新任務路徑採用一條主線流程：

1. 選擇場景。
2. 上傳資料。
3. 選擇自變量與因變量。
4. 開始訓練。
5. 完成訓練後進入預測。

訓練完成後，系統同時支援模型保存、模型選擇與預測輸入。

### 資料上傳

資料輸入支援拖拽與檔案選擇兩種方式，格式包含 `csv`、`xls`、`xlsx`。

系統提供以下行為：

- 頁面提供拖入資料區。
- 頁面提供「選擇文件」按鈕。
- 檔案成功載入後，系統顯示前 5 筆資料預覽。
- 資料預覽在未載入檔案前維持隱藏狀態。

### 變量選擇

在訓練前，使用者需要完成輸入與輸出欄位配置。

規則如下：

- 輸入項至少選 1 個。
- 輸出項固定選 1 個。
- 輸出項需與所有輸入項分離。

系統在完成有效配置後，才開放後續訓練操作。

### 訓練啟動與模型選擇模式

訓練入口為「開始訓練」按鈕。此按鈕在自變量與因變量配置完成後進入可點擊狀態。

原圖定義了兩種訓練啟動方式：

- 當「選擇模式」維持關閉時，使用者直接按「開始訓練」，系統使用預設勾選的模型自動運行。
- 當「選擇模式」展開時，系統進入模型選擇頁，使用者先決定模型與參數，再開始訓練。

模型選擇模式具有以下特徵：

- 模型選擇區平時隱藏，畫面提供提示可展開。
- 畫面列出多個模型，例如模型 1、模型 2、模型 n。
- 每個模型對應一組參數區。
- 使用者透過複選框決定參與訓練的模型。
- 部分模型預先勾選。
- 預先勾選的模型會成為「選擇模式關閉時」的默認運行組合。
- 模型內容可透過文字編輯器編輯。
- 使用者可以按「保存為默認值」保存當前勾選結果，供之後直接訓練使用。

模型選擇頁同時包含以下控制：

- 「確定」按鈕
- 「刪除」按鈕，用於刪除模型
- 「保存為默認值」按鈕
- 「返回上一步」按鈕

「返回上一步」在此處的語義是清空目前資料、模型、參數、自變量與因變量的當前選擇，然後回到前一步重新配置。

### 訓練過程與評估呈現

訓練區以展示為主，使用者在這一段主要觀看進度與結果。

原圖要求包括：

- 畫面顯示訓練過程。
- 訓練過程區不提供互動。
- 畫面顯示模型名稱、訓練狀態、`MSE`、`R平方`。
- 畫面提供提示資訊，用於解釋 `MSE` 與 `R平方` 的含義。

圖中以多模型並列方式呈現結果，形式包括：

- 模型名 1 / 訓練中或訓練完成 / `MSE` / `R平方`
- 模型名 2 / 訓練中或訓練完成 / `MSE` / `R平方`
- 模型名 n / 訓練中或訓練完成 / `MSE` / `R平方`

### 模型保存

原圖在訓練完成後表達了兩層保存行為。

第一層是整體性的「保存模型」按鈕：

- 模型按下「保存模型」後才會真正保存。
- 若使用者是從「選擇過往模型」路徑進入，這個按鈕會被省略。

第二層是模型卡片上的個別保存按鈕：

- 每個候選模型旁都可以出現「保存該模型」按鈕。
- 模型保存完成後，對應按鈕自動轉為不可再次點擊。
- 此設計用於避免同一模型被重複保存。

### 模型保存內容規格

原圖對模型保存內容定義得很完整，保存資料包括：

- 模型檔本體
- 模型參數
- 模型說明
- 模型評估值

模型檔命名規則為：

`時間戳 + 上傳資料檔名 + 模型名稱`

原圖示例：

`2026-03-12-153042-10月份客户价值数据-AdaBoost`

命名構成說明：

- `2026-03-12` 表示年月日
- `153042` 表示 24 小時制的時分秒
- `10月份客户价值数据` 表示上傳資料檔名
- `AdaBoost` 表示保存的模型名稱

原圖同時要求保存一段備註式說明，內容包含：

- 模型建立時間
- 訓練所基於的原始資料檔名
- 輸入變量清單
- 輸入資料前 5 筆示例
- 輸出變量名稱
- 輸出資料前 5 筆示例
- 模型名稱
- 模型參數
- 模型評估值，例如 `MSE` 與 `R平方`

## 預測階段

在訓練完成後，系統進入可預測狀態。原圖將預測拆成兩種輸入方式：

- 單個資料預測
- 檔案輸入預測

這兩種方式被要求做成一個選擇頁。

### 單個資料預測

單筆預測頁的行為如下：

- 系統自動列出所有自變量欄位。
- 使用者可以新增行，也可以刪除行。
- 「開始預測」按鈕在每一項資料完整填寫後才會啟用。
- 預測結果直接顯示在畫面上。
- 結果中需要展示因變量名稱。

### 檔案輸入預測

批量預測頁的行為如下：

- 系統支援拖拽或選擇預測資料檔。
- 支援格式為 `csv`、`xls`、`xlsx`。
- 預測資料成功載入後，畫面顯示前 5 筆預覽。
- 「開始預測」按鈕在檔案成功載入後啟用。
- 預測結果預設顯示前 5 筆。
- 預測結果支援以檔案形式導出。
- 導出的結果同時包含自變量與因變量。
- 結果中需要展示因變量名稱。

### 以特定模型執行預測

原圖在模型結果區為多個模型都放置了「選擇該模型預測」按鈕。

相關規則如下：

- 使用者可以針對任一候選模型發起預測。
- 每按一次該按鈕，結果刷新一次。
- 單筆預測模式沿用「所有資料完整後啟用」規則。
- 檔案預測模式沿用「檔案成功載入後啟用」規則。

### 結果顯示與導出

預測結果在設計中具有兩層表述：

- 畫面直接顯示預測結果。
- 畫面同時支援顯示與導出預測結果。

## 路徑二：選擇過往模型

「選擇過往模型」是另一條起始路徑。這條路徑讓使用者直接基於已有模型進入後續操作。

這條路徑包含以下步驟：

1. 開始時選擇「選擇過往模型」。
2. 選擇場景。
3. 選擇模型。
4. 檢視模型資訊。
5. 確定後進入預測。

原圖對模型選單提出以下要求：

- 模型以下拉選單呈現。
- 模型按時間排序。
- 最新模型排在最前面。
- 每當使用者切換一個模型，畫面立即顯示該模型的相關資訊。

這條路徑的操作按鈕包括：

- 「確定」按鈕
- 「刪除」按鈕，用於刪除模型

這條路徑與新任務路徑的差異包括：

- 訓練完成後才出現的「保存模型」按鈕在此路徑中被省略。
- 針對重新選擇資料、自變量、因變量的返回按鈕在此路徑中被省略。

## 返回規則

原圖定義了兩個返回層級：

第一個返回層級位於預測前的訓練路徑上：

- 使用者可以回到上一步，重新選擇資料、自變量、因變量。
- 回退時，舊的暫存選擇會一併清空。
- 若目前來自「選擇過往模型」路徑，這個按鈕會被省略。

第二個返回層級位於模型選擇模式內：

- 使用者可以回到上一步，重新選擇資料、模型、參數、自變量、因變量。
- 回退時，舊的暫存選擇會一併清空。

## 顯示條件與狀態規則

原圖明確要求了多個 UI 顯示條件：

- 檔案預覽區在載入檔案後顯示。
- 模型選擇區預設維持隱藏，由提示引導展開。
- 「開始訓練」按鈕在輸入項與輸出項配置完成後啟用。
- 單筆預測的「開始預測」按鈕在資料完整後啟用。
- 批量預測的「開始預測」按鈕在檔案成功載入後啟用。
- 模型保存後，對應保存按鈕轉為不可再次點擊。

## 轉寫後的高階結論

這份 SVG 表達的是一個「場景選擇 -> 資料準備 -> 模型訓練或模型選用 -> 預測執行 -> 結果顯示與導出」的整體互動設計。其核心取向有三點：

- 將分析需求先收斂為業務場景。
- 在訓練階段提供默認自動化與顯式模型選擇兩種工作方式。
- 在預測階段同時支援單筆輸入與檔案批量輸入。
