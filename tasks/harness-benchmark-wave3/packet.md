# Harness benchmark 第三批：失败也能成为有效测量

- **目标与授权**：基线 `6666b2f`。用户澄清第三批指整个 benchmark 对 FrontierHarness Eval 的学习，沿用“有高价值改进则实施”的授权。重新评估任务、oracle/Judge、执行、测量、比较与诊断，优先改善失败结果的解释和比较；不继续扩题。
- **形态**：单维护者、一个实现切片；本入口保存决定与 State Diff，独立验证记录保存离线实证。不创建 Track、子 packet 或新评测平台。
- **发现**：当前 `report_policy.py` 把完成、完整性、预算合规当作描述性测量的资格，又要求 Judge 完成才能比较；真实超轮因而不能比较。比较只接受一份 headless 或三份 headless 加一份 headed，缺少普通重复实验的表达。调用总预算还会追溯改判一个已在自身预算内完成的 cell，导致任务顺序影响结果。
- **决定**：学习失败留在结果分母、失败消耗也算投入的原则；把可观察任务结果、评估不可用、资源计量覆盖分开。描述性 characterize/compare 支持任意非空且条件一致的重复集合，保留逐次结果；formal 仍保留原有验收要求。以 token/轮次/时间报告资源，不在没有价格依据时伪造美元成本。
- **边界**：不改变任务题面、oracle、Judge rubric、十二轮等单任务预算；不修改历史报告，不通过推断工具轨迹补出交付。无新增自动化测试；保存报告的显式重投影和一次性边界实验作为证据。第三批改动单独留待审阅。
- **当前状态**：策略 v3、任意重复集合的描述性比较、结果/计量覆盖和调用总预算修正已完成；静态检查、两种模式的默认收集、保存报告重投影及手动边界实验通过，见 [验证记录](verification.md)。用户已批准整理提交，并启动分流超轮根因调查。原失败仍是真实失败；本批不是 Harness 收束修复。

## 一手依据与本地推演

复核固定版本 `8f11b130c30bbf76ca1f3edeea70abc773bd8d2c` 的 [项目说明](https://github.com/frontier-harness-eval/eval/blob/8f11b130c30bbf76ca1f3edeea70abc773bd8d2c/README.md)、[汇总脚本](https://github.com/frontier-harness-eval/eval/blob/8f11b130c30bbf76ca1f3edeea70abc773bd8d2c/skills/frontierharness-eval/scripts/normalize-results.mjs)、[记录约定](https://github.com/frontier-harness-eval/eval/blob/8f11b130c30bbf76ca1f3edeea70abc773bd8d2c/skills/frontierharness-eval/reference.md) 和 [冻结定义](https://github.com/frontier-harness-eval/eval/blob/8f11b130c30bbf76ca1f3edeea70abc773bd8d2c/benchmark.json)。其明确区分基础设施无效与任务失败/超时，以所有有效任务的总成本除以成功数，并在成本证据不足时留空。固定有效尝试避免挑选最优重跑；本地改为保留显式提供的全部重复，不自动择优。

不照搬其容器、黄金快照、单一模型或二元排行榜。Xenix 需要保留 partial、Judge 不可用、跨请求交付、headed 验证和资源缺失事实；四个家族也不支持宣称总体生产成功率。其公开仓库不含完整冻结 verifier，本次没有假称审计全部评分实现。重复集合和报告策略改进是本地推演，非声称 Frontier 已实现同款接口。

## From → To State Diff

| 对象 | From | To |
| --- | --- | --- |
| 任务结果 | structural、Judge、执行分散，超轮在描述性比较前被排除 | 单独投影 pass/partial/fail/unscored；超轮和运行失败保留，Judge 不可用不伪造成失败或通过 |
| 描述性实验 | 只允许单 headless 或固定 3+1 | 任意非空、同任务同条件的重复集合；逐次展示结果，仍检查决定比较意义的身份 |
| 资源解释 | 仅中位 token/时间差，未知使用量可能看成不完整小值 | 所有尝试的已观察消耗与计量覆盖；完整计量且有成功时给出总 token/成功数 |
| 调用总预算 | 越过调用上限会把已完成 cell 改成 budget_exceeded | 保留该 cell 自身状态、完整结果和调用总量，在调度边界停止后续任务 |
| 验收 | formal 混合了测量资格与通过要求 | 描述性失败可比较；formal 原通过标准继续独立适用 |

验证复用了已保存真实报告，保留旧策略输出及新策略输出；新增 Subject 与 Judge 调用均为零。
