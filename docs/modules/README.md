# Modules

This directory contains technical documentation for cross-cutting modules and shared concerns.

## Available Modules

| Module                | Description                                 |
| --------------------- | ------------------------------------------- |
| frontend-architecture | Frontend codebase organization and patterns |
| backend-architecture  | Backend API structure and conventions       |
| database-schema       | Database entities and relationships         |
| ml-pipeline           | Machine learning workflow implementation    |
| deployment            | Deployment configurations and guides        |
| i18n                  | Internationalization setup and guidelines   |

## Module Template

Each module document should include:

1. Purpose and scope
2. Key concepts
3. Architecture overview
4. API/contracts
5. Usage examples
6. Related features
