# 审计中心与 Agent 解释

审计中心服务于不具备专业审计能力的业务用户，默认先回答采用方法的原因、结果的业务含义及其限制，再提供可追溯的输入、执行参数和原始记录；不能用任务成功或一段 Agent 解释代替证据，也不计算笼统的信任分数。

## 事实与解释的所有权

DatasetService、MLTaskService 和 ArtifactService 继续拥有各自产出、参数及结果，AuditQueryService 只组合这些权威记录；UI 不读取数据库、日志路径或推测文件关联。
数据派生操作、绘图及模型训练、调参和应用工具要求非空业务理由，工具适配器从 ToolExecutionContext 注入来源会话与工具调用身份，不能让模型填写身份字段。
来源随派生数据、Artifact 注册或 ML 任务创建持久化，不依赖工具结果回包，因此超时继续运行、评估自动续作和部分产出仍有来源；自动评估继承根训练任务的来源。
执行请求记录已解析的模型参数及执行配置，提交参数与调参最终选中参数分别展示；历史上未保存的值保持未知，不按今天的默认值补齐。
数据派生保留原有参数记录和有序输入别名；绘图在数据注入边界保存不含注入行的执行配置，词云记录实际使用的绘制选项。

`audit.list` 查找当前会话产出，`audit.inspect` 读取证据，`audit.explain` 将结果解读及其引用追加保存；纠正解释会产生新版本，不修改领域事实或历史解释。
结果解读说明观察到的结果、业务含义、适用限制及用户可检查的事项，引用必须指向存在且与当前会话或产出关联的对象；未结束的任务不能被登记为已有结果解读。
新会话系统提示和产出工具参数说明要求保存结果解读；旧会话通过当前工具目录获得此能力，原系统提示和工具结果不被重写。
后台任务完成不会自行启动新的付费 LLM 请求；尚无解读时界面明确显示缺口，下一次 Agent 处理可使用审计工具补充解释。

## 范围与导航

两个中心默认选择当前会话，无当前会话时显示空状态；所有会话是用户显式选择的范围。
审计中心当前范围包含在本会话生成或通过公开对象句柄明确引用的产出；跨会话复用不改变原生成来源，后续解读归属撰写它的会话。
任务中心当前范围只包含本会话发起的 ML 任务及自动评估，不因为另一会话引用模型而迁移任务；全局 Knowledge 任务和来源不明的历史任务出现在所有会话范围。
保留模型和应用 Dataset 作为主对象，已归属于这些对象的模型文件和数据导出不重复充当主产出；报告和图表仍可独立审计。
证据引用可进入上游对象并返回原产出；任务中心按任务定位审计产出，审计中心按任务定位执行状态和日志。
文件操作只能发出 Artifact URI，经既有 LinkRouter 和 ArtifactService 打开；文件丢失不妨碍查看解释和记录，但打开操作不可用。
来源会话删除不级联删除领域产出或解释；历史来源仅沿持久化工具创建关系回填，查询任务的会话不能被误认作发起会话。

## UI 与生命周期

AuditCenterDialog 默认显示“解释与证据”，其他页为“输入与来源”和“参数与记录”，原始记录及解读历史按需展开。
JobCenterDialog 承接任务状态、时间、错误和日志，取消仍由 JobScheduler 决定能力并执行；训练消息专属详情按钮及旧详情窗口已移除，通用工具结果展开、任务查询和停止工具继续存在。
Application Composition 构造查询服务与窗口工厂，AuxiliaryWindowCoordinator 持有两个无模式窗口；ChatWorkspace 的会话变化通过主窗口传递，UI 不另建服务容器。
列表和详情异步读取，代次检查丢弃过期回包；详情通道只保留最新待执行读取，隐藏停止轮询，退出等待已开始的读取完成。

## 验证入口

`tests/test_audit_service.py` 验证范围、证据、解释版本、跨会话复用与文件/会话丢失；`tests/storage/test_audit_migration.py` 验证前向升级、当前 ORM 读取及事务回滚。
`tests/ui/test_audit_center.py` 与 `tests/runtime/test_job_center.py` 验证异步代次、筛选、取消和中心导航；`scripts/ui_lab/audit_scenarios.py` 用合成证据驱动生产控件，覆盖中英文、紧凑布局、未解读、历史缺失、截断图表和任务失败状态。
自动化验证保存的是结构与交互契约，不证明某次真实 Agent 解读的业务判断正确；该判断仍需要对照本次任务证据。
