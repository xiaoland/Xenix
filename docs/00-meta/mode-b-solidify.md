# Mode B - Solidification

## Trigger

Use this mode when the request is becoming specific, but the durable home for each truth is not fully settled yet.

## Constraints

- Classify truths before editing anything durable.
- Restate scope, invariants, and likely affected files before writing.
- Wait for confirmation before updating durable docs or code.

## Read-Do

1. Sort product truth into PRD, technical truth into TDD, and temporary reasoning into tasks.
2. Restate the target, current state, operation, scope, invariants, and uncertainty.
3. Ask for confirmation on the proposed destination and change set.

## Exit

Leave this mode after the scope is confirmed and the durable destinations are clear.
