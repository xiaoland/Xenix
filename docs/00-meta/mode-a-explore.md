# Explore Overlay

## Trigger

Use this overlay when causality is unclear, the scope is still unstable, or multiple viable paths need comparison before durable mutation.

## Preconditions

- Root `AGENTS.md` has already been consulted.
- The current work has been roughly classified as `Intent`, `Constraint`, `Reality`, or `Artifact`.
- An agent-owned task packet exists under `tasks/<task-slug>/`.

## Constraints

- Do not treat this overlay as a durable owner.
- Keep the work in the active task packet and preserve a compact current-state surface.
- Search source and durable docs with volatile task workspaces, generated output, dependencies, virtual environments, and caches excluded unless the active question targets them.
- Prefer current facts, hypotheses, unknowns, and candidate paths over premature decisions.
- Durable docs and code stay unchanged while the task is still genuinely exploratory.

## Read-Do

1. Record `Objective & Hypothesis`, `Guardrails Touched`, and `Verification`.
2. Capture current understanding, unknowns, assumptions, candidate paths, and next step.
3. Identify the smallest confirmation or evidence needed to reduce ambiguity.
4. Decide whether the next posture is `Solidify`, `Diagnose`, or a narrower `Explore` slice.

## Exit

Leave this overlay when the owner and change shape are clear enough to restate precisely, or when the work becomes evidence-first diagnosis.
