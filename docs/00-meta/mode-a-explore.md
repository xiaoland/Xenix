# Mode A - Exploration

## Trigger

Use this mode when the request is vague, the root cause is unknown, or the desired change is still being discovered.

## Constraints

- Do not edit durable docs or production code.
- Work only in `tasks/`.
- Prefer questions, hypotheses, and gap mapping over implementation.

## Read-Do

1. Capture the current understanding in a task note.
2. List unknowns, assumptions, and candidate paths.
3. Identify the smallest confirmation needed to move forward.

## Exit

Leave this mode when the scope is stable enough to classify truths for Mode B.
