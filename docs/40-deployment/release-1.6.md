# 1.6.0 发布说明

本版本将数据集 lineage 扩展为统一审计中心，让用户通过 Agent 的通俗解释理解产出及其依据。用户已于 2026-09-20 完成手动验收并授权发布；本文随版本准备提交，实际发布结果以 [Native Release](https://github.com/xiaoland/Xenix/actions/workflows/native-release.yml) 和 OSS 正式更新源为准。

## 用户可见变化

- 审计中心覆盖数据集、训练模型、图表、报告和模型应用结果，优先显示方法选择理由与结果解读，并提供输入来源、实际参数和证据。历史缺失的来源或尚未完成的解读会明确标识，不补造解释。
- Agent 创建产出时保存方法理由，训练及调参按模型分别说明；结果解读保留追加版本，用户可检查解释的上下文及修订记录。
- 任务中心支持当前会话和全部会话范围，集中呈现任务状态、错误、日志与取消操作，并与审计中心相互定位。
- 训练消息专属“查看详情”入口及旧详情窗口移除，其任务信息由任务中心承接，产出审计由审计中心承接。

## 升级说明

本版本将本地数据库升级至 schema v29，新增产出来源和解释版本记录。历史回填仅采用能够证明的创建关系；不确定的历史来源保持未知，跨会话引用不会改变原产出的创建会话。
应用更新前的数据库备份和迁移恢复遵循 [Windows Distribution](windows-distribution.md) 与 [Local State Evolution](local-state-evolution.md)；降级安装包不会自动降级数据库。

## 验证与发布边界

功能实现已通过 318 项自动化测试、静态检查和隔离启动检查；16 个 UI Lab 场景、原生 Qt 100%/150% DPI 检查以及用户手动验收均已完成。来源写入、旧库升级回滚、真实子进程登记、实际绘图和脚本化 Agent 解释闭环的证据见 [功能验收记录](../../tasks/audit-center/results.md)。
v1.6.0 必须从版本准备 PR 合入后的 main 提交创建标签，完成 release identity 检查后，由正式流水线从同一标签重新构建并运行打包烟雾检查、Velopack 和发布验证；先前审阅包不作为本版本发布产物。发布清单记录最终提交、标签、构建环境、文件哈希及验证结果。
