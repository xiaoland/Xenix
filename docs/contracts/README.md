# Contracts

Contracts are the source of truth for integration semantics in the native app. They define what must hold between modules even when internal implementations change.

- `runtime-boundaries.md`: UI, service, and ML responsibilities.
- `task-lifecycle.md`: task states, logs, and result-file guarantees.
- `storage-ownership.md`: SQLite versus filesystem ownership.
- `product-scope.md`: product concepts kept or removed for single-user native mode.
