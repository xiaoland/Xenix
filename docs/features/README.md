# Features

This directory contains Product Requirements Documents (PRDs) for each feature.

## Structure

Each feature folder contains:

- **PRD.md** - Product Requirements Document
- **HLD.md** - High-Level Design (if needed)
- **LLD.md** - Low-Level Design (if needed)

## Features

| Feature    | Status    | Description                                  |
| ---------- | --------- | -------------------------------------------- |
| auth       | ✅ Active | Authentication (signin/signup)               |
| projects   | ✅ Active | Project management (CRUD)                    |
| work-items | ✅ Active | ML workflow items (Prepare → Tune → Predict) |
| datasets   | ✅ Active | Dataset upload and management                |
| tasks      | ✅ Active | Background task monitoring                   |
| ml         | ✅ Active | ML-specific functionality                    |

## Status Legend

- 🚧 Planned - Not yet implemented
- 🔄 In Progress - Currently being developed
- ✅ Active - Fully implemented and maintained
- 📦 Archived - Feature deprecated or removed
