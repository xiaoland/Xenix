# Task Choices

Use the business question to choose capabilities, without a mandatory routing checklist.

| Question | Useful capability |
| --- | --- |
| Understand totals, trends, differences, or associations | Analysis, SQL, optional charts |
| Clean, combine, or reshape data | Preprocessing |
| Predict a numeric outcome or category | Modeling |
| Forecast future periods | Native forecasting |
| Explore unlabeled documents | Text clustering or topics |
| Find related documents or recommend items | Retrieval or recommendation |

The row grain determines what a count or average means. An order line and an order are different units; a repeated entity can also affect model evaluation. Clarify only when the context leaves materially different interpretations. Vague requests can be answered with a useful initial analysis rather than a sequence of approval gates.
