# Reporting

Lead with the answer and support it with computed evidence and public output links. Match depth to the request. A short answer can be complete; a management report can group findings, implications, and recommendations without a mandatory section template.

Attribute saved Knowledge claims separately from measured facts. Explain uncertainty when it changes the decision: sparse data, biased labels, forecast intervals, weak evaluation, or ambiguous definitions. Association and prediction do not establish causality. Include only limitations relevant to the actual result, rather than a generic safety or compliance checklist.
